# Givewise Insights

Founder-led technology strategy and advisory for organizations making decisions about AI, automation, data, digital systems, and operations.

## Positioning

Givewise Insights helps leaders clarify technology decisions before they commit budget, adopt tools, automate workflows, or modernize systems.

Core advisory areas:
- Technology Strategy
- AI & Automation
- Data & Decision Systems
- Digital Operations

## Architecture

This launch site is intentionally static and dependency-free for speed and reliability on Vercel:
- `index.html` — semantic site structure and SEO metadata
- `styles.css` — responsive visual system
- `script.js` — mobile navigation, reveal effects, and FormSubmit contact handling
- `robots.txt` / `sitemap.xml` — search indexing
- `vercel.json` — caching and security headers

## Contact

The inquiry form uses FormSubmit and routes messages to the configured founder email.
